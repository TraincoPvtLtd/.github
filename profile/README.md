## 👋 About Us

Welcome to the official GitHub home of **Trainco (Pvt) Ltd**.

This space belongs to our **IT Department**, the team that designs, builds and maintains the company's software products. We are a team of full-stack developers working across mobile, web and backend systems.

## 📦 Featured Project

### 🛠️ HIRE US

A gig-work marketplace that connects **residential and industrial clients** with **verified service providers and contractors** such as welders, plumbers and electricians.

| Component | Platform |
|---|---|
| 👷 Provider App | Android & iOS |
| 🏠 Residential Client App | Android & iOS |
| 🏭 Industrial Client App | Android & iOS |
| 🖥️ Admin Panel | Web |
| ⚙️ Backend API | Spring Boot |

**Status:** 🚧 In development, with the first launch planned for the Colombo and Gampaha districts.

👉 See the **HireUs** repository for full details.
